## Access Control

Capability parameters can be given bounds in the form of concrete capture sets. This allows restricting what a block can capture:

```scala
trait AccessControl:
  def runSecure[C^ <: {trusted}](block: () ->{C} Unit): Unit

  // 'brand' capability to mark what can be mentioned in trusted code
  object trusted extends SharedCapability

  val trustedLogger: Logger^{trusted}
  val trustedChannel: Channel[String]^{trusted}
  val untrustedLogger: Logger^
  val untrustedChannel: Channel[String]^

  def main() =
    runSecure: () =>
      trustedLogger.log("Hello from trusted code") // ok
    runSecure: () =>
      untrustedLogger.log("I can't be used")       // error
```

Every capability derived from the marker capability `trusted` (and only those) is eligible to be used in the `block`. This is enforced by the explicit capability parameter `C^ <: {trusted}`.

An equivalent formulation using implicit capture polymorphism:

```scala
trait API:
  object trusted extends SharedCapability
  def runSecure(block: () ->{trusted} Unit): Unit
```

## Capture-Safe Lexical Control

Capability members and path-dependent capabilities can prevent leakage of labels for lexically-delimited control operators:

```scala
trait Label extends SharedCapability:
  type Fv^  // capability set occurring freely in the block passed to boundary

def boundary[T, C^](block: Label{type Fv = {C}} ->{C} T): T = ???
def suspend[U](label: Label)[D^ <: {label.Fv}](handler: () ->{D} U): U = ???
```

`suspend` (analogous to `shift` from delimited continuations) targeting a specific label must not accidentally close over labels from nested `boundary` scopes, as they would escape their defining scope.

The mechanism:
- `Label`s store the free capabilities `C` of the block in capability member `Fv`
- When suspending on a label, the handler can capture at most the capabilities free at the `boundary` that introduced the label
- This prevents mentioning nested bound labels at compile time

```scala
boundary: outer =>
  boundary: inner =>
    val w = suspend(outer) {() => z} // ok
    suspend(outer): () =>            // error (would leak inner label)
      println(inner)
```
