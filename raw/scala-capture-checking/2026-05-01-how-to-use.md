# How to Use the Capture Checker

> Source: https://raw.githubusercontent.com/scala/scala3/main/docs/_docs/reference/experimental/capture-checking/how-to-use.md
> Collected: 2026-05-01
> Published: Unknown

## Enabling Capture Checking

Add to any file using the feature:

```scala
import language.experimental.captureChecking
```

### Separation Checking

```scala
import language.experimental.captureChecking
import language.experimental.separationChecking
```

### SBT Project Template

Pre-configured template: https://github.com/lampepfl/scala3-cc-template

### REPL / Scala-CLI

```bash
scala -S 3.nightly -language:experimental.captureChecking
```

Or in a file with the directive:

```scala
//> using scala 3.nightly
import language.experimental.captureChecking
```

Then run with `scala foo.scala`.

## API Documentation

Scaladoc supports capture checking. Nightly standard library API docs have it enabled by default: https://nightly.scala-lang.org/api/

## Useful Compiler Flags

- `-Vprint:cc` — Shows the program with inferred capturing types
- `-Ycc-verbose` — Displays capabilities and capturing types in greater detail
- `-Ycc-debug` — Provides implementation-focused information about the capture checking process
